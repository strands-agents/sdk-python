[strands-stigmer](https://github.com/LNSHRIVAS/stigmer) gives Strands
agents the **execution graph of AWS**: verified method contracts with
required parameters, IAM permissions, pagination contracts, call-chain
links, and known traps. Common workflows ship with a generated
least-privilege IAM policy.

Backed by [Stigmer](https://stigmer.network), an open MCP knowledge
network with 30,000+ verified contracts across 380 AWS services (boto3
and aws-sdk-js).

## Installation

```bash
pip install strands-stigmer
```

## Usage

```python
from strands import Agent
from strands_stigmer import stigmer_query

agent = Agent(tools=[stigmer_query])

# Get the call sequence and IAM policy for a multi-step workflow
agent("I need to upload a 5GB file to S3 with KMS encryption. "
      "What's the sequence and IAM policy?")

# Scope to one SDK for precise contracts (boto3 or aws-sdk-js)
stigmer_query("list objects", library="boto3")
```

## Key Features

- **Verified method contracts**: machine-extracted from botocore's
  service definitions (the exact JSON the AWS SDKs are generated from)
- **IAM permissions**: the exact actions each method requires,
  from iann0036/iam-dataset
- **Least-privilege policies**: generated for common workflows
  (S3 multipart upload, assume-role-to-S3, DynamoDB CRUD, Lambda)
- **Call-chain links**: what outputs thread into which downstream calls
- **Traps and gotchas**: pagination contracts, async-waiter annotations,
  declared error types, Stack Overflow gotchas, and agent write-backs

## Configuration

No API key required. The tool queries the hosted endpoint at
`https://stigmer.network/mcp`. An optional read-only endpoint is
available at `https://stigmer.network/mcp-readonly` for strict
environments.
