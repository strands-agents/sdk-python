[strands-agt](https://github.com/lizradway/strands-agt) provides deterministic, YAML-based policy enforcement for Strands Agents using Microsoft's [Agent Governance Toolkit (AGT)](https://github.com/microsoft/agent-governance-toolkit). It gates tool calls before execution with no model judgment involved.

## Installation

```bash
pip install strands-agt
```

## Usage

```python
from strands import Agent
from strands_agt import AGTGovernance

governance = AGTGovernance(policies="policies.yaml")
agent = Agent(tools=[...], interventions=[governance])
result = agent("search for documents")
```

## Policy Format

Policies are defined in YAML with three effects:

| Effect | Strands Action | Behavior |
|--------|---------------|----------|
| `allow` | `Proceed()` | Tool executes normally |
| `deny` | `Deny(reason=...)` | Tool is blocked, reason shown to model |
| `steer` | `Guide(feedback=...)` | Tool is blocked with corrective guidance |

```yaml
policies:
  - name: allow-search
    effect: allow
    actions: ["search"]
    principals: ["User::*"]

  - name: deny-delete
    effect: deny
    actions: ["delete_file"]
    reason: "File deletion is not permitted"
```

Evaluation is fail-closed: deny policies are checked first, then steer, then allow. No match means deny.

## Features

- Role-based access control via `principal_resolver`
- Rate limiting with session call count conditions
- Context enrichment for environment-aware policies
- Condition operators: `lt`, `lte`, `gt`, `gte`, `eq`, `neq`, `in`
